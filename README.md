# nixos

Declarative NixOS configuration for a **ThinkPad E14 Gen 6 (Intel)** — a
keyboard-driven Wayland desktop built around remote development.

Flakes + Home Manager + Stylix, targeting NixOS 26.05 "Yarara".

## The stack

| | |
|---|---|
| Compositor | Hyprland |
| Bar | waybar — floating pill islands |
| Terminal | kitty + zellij |
| Editor | Neovim (patched kickstart) + `claudecode.nvim` |
| Shell | fish + starship + atuin + direnv + fzf + zoxide |
| Launcher | fuzzel |
| Browser | Firefox, uBlock Origin + Bitwarden installed by policy |
| PDF | zathura for reading, okular for annotating |
| Files | yazi |
| Mail | Thunderbird, with aerc alongside |
| Writing | LaTeX (texlive subset) + Typst |
| Theme | Stylix — Gruvbox Material dark medium |
| Secrets | sops-nix, age keys derived from the SSH host key |
| Networking | Tailscale, NetworkManager + iwd |

Caps Lock is Escape system-wide via `keyd`, including in the TTY.

## Design decisions

**Remote-first.** This machine has no GPU; training happens on remote compute
nodes. So the config optimises for SSH ergonomics — declared port forwards so
connecting makes a remote Jupyter appear on localhost, connection multiplexing
for instant reconnects, kitty's ssh kitten to fix terminfo on Ubuntu servers,
mosh for unreliable links.

**No private hostnames in git.** `home/jerzy/ssh.nix` holds only the global
defaults and `github.com`. Real hosts and addresses live in a sops-encrypted
secret that's `Include`d at runtime, so this repo is safe to publish without
advertising internal infrastructure.

**Dotfiles stay portable.** Everything in `dotfiles/` is a plain config file,
symlinked with `mkOutOfStoreSymlink` rather than generated by Nix. That means
(a) editing it takes effect without a rebuild, and (b) the same directory can be
cloned onto a remote box that has never heard of Nix. Neovim is deliberately
excluded from Stylix theming for the same reason — it looks identical on every
machine.

**Nix owns what's machine-specific.** Waybar and kitty are configured in Nix
because they're never needed remotely, and being in Nix lets them read the
Stylix colours.

**Mason is gone.** `dotfiles/nvim/` is a patched copy of kickstart.nvim with
mason.nvim removed — it downloads prebuilt binaries that can't run on NixOS.
Language servers are installed declaratively instead. Every change from upstream
is marked with a `NIXOS:` comment.

**Escape hatches on purpose.** `programs.nix-ld` makes `uv pip install torch`
behave like it does on Ubuntu, and `distrobox` is there for anything that
refuses to cooperate at all.

## State of this repo

Everything evaluates as committed — no missing files, nothing to create before a
first build. Two features ship **disabled** because enabling them requires files
that can only exist on your machine:

| Disabled | Where | Enable after |
|---|---|---|
| Wallpaper | `modules/nixos/style.nix` | first boot — add the image, `git add` it, uncomment two lines |
| Secrets (eduroam, SSH hosts, tokens) | `modules/nixos/secrets.nix` and `net.nix` | [docs/SECRETS.md](docs/SECRETS.md) steps 1–3 |

Both are Nix **path literals**, which must exist at evaluation time — pointing
one at a missing file fails the entire build rather than just that feature. That
is the single most common way this config breaks, so it's disabled by default
and each site says so inline.

`hosts/thinkpad/hardware-configuration.nix` is committed and matches this
specific machine. Regenerate it for any other.

## Verify before you build

```bash
./scripts/check-tree.sh
```

Checks two failure modes that produce identical-looking errors but have
different fixes: a file missing from disk, versus a file present but **untracked
by git**. Flakes only evaluate tracked files, so an untracked file reports
`path '...' does not exist` even though `ls` shows it plainly. Run this before
every install and after copying files in.

## Quick start

Full walkthrough in [docs/INSTALL.md](docs/INSTALL.md). The short version, from
a NixOS live USB:

```bash
# partition, then:
git clone https://github.com/YOURNAME/nixos /mnt/etc/nixos-config
cd /mnt/etc/nixos-config
nixos-generate-config --root /mnt --no-filesystems
cp /mnt/etc/nixos/hardware-configuration.nix hosts/thinkpad/
nixos-install --flake .#thinkpad --root /mnt
```

Day to day:

```bash
nrs                 # rebuild and switch
nrt                 # rebuild without adding a boot entry
nix flake update    # bump inputs
```

## If you're forking this

Three things are specific to me and will break for you:

1. **Username.** `jerzy` appears in `flake.nix`, `modules/nixos/base.nix`,
   `modules/nixos/secrets.nix` and `home/jerzy/`.
2. **Hardware.** `flake.nix` imports
   `nixos-hardware.nixosModules.lenovo-thinkpad-e14-intel-gen6`. Find yours in
   the [nixos-hardware](https://github.com/NixOS/nixos-hardware) README.
3. **Secrets.** `.sops.yaml` lists my public keys. Replace them and create your
   own `secrets/secrets.yaml`; see [docs/SECRETS.md](docs/SECRETS.md).

Also: locale is `en_US.UTF-8` with a Polish keyboard layout and `Europe/Warsaw`,
and fcitx5 is set up with Chinese input methods. Adjust `base.nix` and
`desktop.nix`.

## Known rough edges

- **Neovim needs 0.12+** for `vim.pack`. Check `nvim --version`; if stable ships
  0.11, uncomment `unstable.neovim` in `packages.nix`.
- **`stylix.image`** points at `modules/nixos/wallpaper.jpg`, which isn't in the
  repo. Add one or comment the line out, or evaluation fails.
- **A few package names are unverified** — `wiremix`, `hyprshot`, `tinymist`,
  `nvtopPackages.intel`, `bibata-cursors`. Fix with `nix search nixpkgs <name>`.
- **`programs.ssh.enableDefaultConfig`** only exists in newer home-manager.
  Delete the line if evaluation complains.
- **No hibernate** — `zramSwap` instead of a swap partition. Suspend works.
